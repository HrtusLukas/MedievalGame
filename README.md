# ⚔️ 2D RPG Adventure Game (JavaFX)

A 2D top-down RPG game built with **JavaFX** as a **first-year university Object-Oriented Programming (OOP)** project in Java. The game features WASD character movement, combat, item interactions, quests, and multiple unique NPCs leading up to a final boss fight.

---

## 🎮 Controls

| Action | Input | Description |
| :--- | :--- | :--- |
| **Movement** | `W`, `A`, `S`, `D` | Move character Up, Left, Down, and Right |
| **Attack** | `RIGHT_CLICK` | Attack target NPC or enemy |
| **Interact / Pick Up** | `LEFT_CLICK` | Pick up items, talk to NPCs, and interact with the world |

---

## 🎭 Characters & NPCs

- 👑 **King:** Main questgiver who advances the primary story.
- 🛡️ **Knight:** Castle guard; can be attacked in combat.
- 🪙 **Merchant:** Trader who sells items, gear, and consumable goods.
- 🏡 **Villager:** Local inhabitant offering side quests and information.
- 🗡️ **Bandit:** Hostile enemy encountered in the world; can be engaged in combat.
- 🔮 **Warlock:** The Final Boss of the game; can be challenged and defeated in the ultimate showdown.

---

## 🛠️ Built With

* **Language:** Java 17+
* **GUI Framework:** JavaFX / OpenJFX
* **OOP Concepts Demonstrated:**
  * **Inheritance & Abstraction:** Base classes for Entities, Characters, and Items.
  * **Encapsulation:** Private fields with controlled getters/setters for health, inventory, and stats.
  * **Polymorphism:** Unique behaviors for different NPC types and interaction handling.
* **IDE / Build System:** IntelliJ IDEA, Maven / Gradle
