This is a first-year university project focused on object-oriented programming in Java.

Contols: 
    Movement: W,A,S,D
    Attack: RIGHT_CLICK
    Picking items, interactions, LEFT_CLICK

NPC´s:
    King: questgiver
    Knight: can be attacked
    Merchant: sells items
    Bandit: can be attacked
    Villager: questgiver
    Warlock: final boss, can be attacked
